# 快速启动（Portable）

> 说明：启动脚本已整理到 `scripts/` 目录；项目根目录仍保留同名脚本用于兼容“双击启动”。

## 运行

### Windows

1. **推荐**双击：`Start_AG_Matrix_SAFE.bat`
   - 这是安全模式：**不会**自动 `taskkill` 占用端口的进程
2. 浏览器会自动打开：`http://127.0.0.1:8080/`
3. 在 WebUI 里用 **Start/Stop** 按钮控制核心 worker（跟单/监听等）

### macOS

1. 先确保已安装 `python3`（推荐 3.11+）
2. 首次使用请在项目根目录执行一次（给脚本可执行权限）：
   - `chmod +x ./Start_AG_Matrix_SAFE.command`
   - （可选）`chmod +x ./Start_AG_Matrix_ALL.command`
   - （可选）`chmod +x ./Stop_AG_Matrix.command`
3. **双击** `Start_AG_Matrix_SAFE.command` 启动（首次会自动安装依赖并下载 Playwright Chromium）
4. 浏览器会自动打开：`http://127.0.0.1:8080/`
5. 如果你希望**一键启动全部进程**（监听/跟单/WebUI/保活），可改为双击：`Start_AG_Matrix_ALL.command`

## 停止

- 先在 WebUI 点 **Stop**（停止核心 worker）
- 然后关闭启动脚本所在的终端窗口（关闭 WebUI 服务）
  - Windows：关闭运行 `Start_AG_Matrix*.bat` 的黑色命令行窗口
  - macOS：关闭 Terminal 窗口或 `Ctrl+C`
- macOS（可选）：如果你是用 `Start_AG_Matrix_ALL.command` 启动的，可双击 `Stop_AG_Matrix.command` 一键停止全部进程（或在 `app/` 下执行 `python app.py stop`）

## 常见问题

### 端口 8080 被占用

- `Start_AG_Matrix_SAFE.bat` 会提示占用的 PID
- 解决方案：
  - 关闭占用 8080 的程序后重试；或
  - 打开 `Start_AG_Matrix_SAFE.bat`，把 `set "PORT=8080"` 改成其它端口（例如 `18080`），再重新双击运行

macOS：
- 终端里用其它端口启动：
  - `PORT=18080 ./Start_AG_Matrix_SAFE.command`

### 日志在哪里看

- ALL 模式（`Start_AG_Matrix_ALL.command`）日志：`data/logs/*.out.log`、`data/logs/*.err.log`
- SAFE 模式（仅 WebUI）日志：终端输出为主；核心 worker 日志同样在 `data/logs/`
- 结果明细：`app/data/follow_results.jsonl`
- 诊断接口：`http://127.0.0.1:8080/api/diagnostics`

## 抓接口/抓包（排查主盘→附加盘找不到盘口线）

输出位置：`app/data/captures/`（jsonl + 截图）。

### 交互模式（推荐）

用于手动登录/手动进入“更多盘口/附加盘”页面，避免脚本自动退出。

```bash
HGA_HEADLESS=0 HGA_TIMEOUT=300 python3 app/tools/capture_hga027_endpoints.py
```

如需指定抓包站点（覆盖默认域名），加上：
```bash
HGA_BASE_URL="https://mos077.com" HGA_HEADLESS=0 HGA_TIMEOUT=300 python3 app/tools/capture_hga027_endpoints.py
```

看到终端提示后：
1. 在弹出的浏览器里完成登录，并进入要复现的比赛页面
2. 回到终端按一次回车：开始抓包
3. 在浏览器里切换主盘/附加盘/更多盘口，等待 10~20 秒
4. 回到终端再按一次回车：结束并保存（会打印 jsonl/png 路径）

可选：自动停止（不用按回车）
```bash
HGA_HEADLESS=0 HGA_AUTO_STOP_SECONDS=30 python3 app/tools/capture_hga027_endpoints.py
```
